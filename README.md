# Short Description
This project helped me learn how to clean a raw sales dataset using Python and GitHub Copilot. The project loads the raw CSV file given, cleans the columns, fixes missing values, removes invalid data, and then saves the cleaned version into the 'processed' folder.
# Run Instructions
1. Open terminal
2. Go to the project folder "cd ism2411-data-cleaning-copilot"
3. Run the Python Script "python src/data_cleaning.py"
4. After in runs error free, the cleaned file will be created here : data/processed/sales_data_clean.csv
5. A preview of the first few cleaned rows should also appear in the terminal.
