For this project, I relied on GitHub Copilot's help a lot because I am not very good in Python yet. To get Copilot to help me, I wrote comments above the functions explaining what I wanted them to do. After I typed the comments, Copilot gave me some suggestions for the functions. It gave me most of the structure for load_data(), clean_column_names(), handle_missing_values(), and remove_invalid_rows(). Sometimes it even filled in parts of the code before I really knew how to write them myself, which made it easier for me to understand what I needed to do.
Even though Copilot wrote most of the starting code, I still had to make changes to go along with  my dataset. For example, in load_data(), I added a print statement so I could tell which file was being loaded since I kept getting confused. In clean_column_names(), I made sure the column names were stripped of extra spaces because my raw data had a lot of that. For handle_missing_values(), I changed the logic so that both price and qty became numbers, and then I dropped the rows that still had missing values. I also changed the filtering in remove_invalid_rows() to check for negative numbers in both columns at the same time. These changes were mostly made because I was following the assignment instructions and fixing things Copilot didn’t fully get right.
